# Module Documentation

One document per module (matching `src/modules/*`) explaining its domain rules in plain language - e.g. what statuses a loan application can move through, or who can assign a lead to whom.

For a loan DSA business, these rules are the actual product. Undocumented business rules become tribal knowledge that leaves with the developer who wrote them. Use `_TEMPLATE.md` as a starting point for each module doc.
