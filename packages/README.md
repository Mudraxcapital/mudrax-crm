# Packages (npm workspaces)

| Package | Name | Role |
| --- | --- | --- |
| `api/` | `@mudrax/api` | HTTP client for existing CRM APIs |
| `shared/` | `@mudrax/shared` | Constants, permissions, validation, utils |
| `types/` | `@mudrax/types` | Shared serializable types |

Installed from the repo root via `npm install` (`workspaces` in root `package.json`).
